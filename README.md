# فالوور پلاس (Follower Plus)

پروژه‌ی اولیه‌ی اندروید با Kotlin و Jetpack Compose، با تم مشکی/طلایی و نماد موقت فلفل.

## اجرا
1. Android Studio را نصب کنید.
2. این پوشه را با گزینه‌ی Open باز کنید.
3. منتظر بمانید Gradle Sync کامل شود.
4. برای اجرای آزمایشی روی گوشی، Run را بزنید.
5. برای ساخت APK: از منوی Build گزینه‌ی Build APK(s) را انتخاب کنید.

## وضعیت این نسخه
این یک نمونه‌ی اولیه‌ی رابط کاربری است، نه سرویس آنلاین آماده:
- ورود فعلی فقط اعتبارسنجی نمایشی شماره است و پیامک واقعی نمی‌فرستد.
- کیف پول و سفارش‌ها هنوز به سرور وصل نیستند.
- پنل مدیریت فعلاً نمایشی است.
- برای نسخه چندکاربره باید سرویس احراز هویت پیامکی، پایگاه داده، API امن و درگاه پرداخت انتخاب و پیکربندی شوند.
- کلیدهای محرمانه و اطلاعات درگاه نباید داخل اپ اندروید قرار بگیرند.

## محدوده خدمات
قابلیت‌های قابل پیاده‌سازی شامل تحلیل آمار، مدیریت محتوا، زمان‌بندی انتشار و خدمات قانونی تولید محتواست. فروش فالوور جعلی یا تعامل مصنوعی و دست‌کاری آمار در این نمونه پیاده‌سازی نشده است.

## ساخت APK بدون کامپیوتر (با گوشی)
این پروژه یک workflow برای GitHub Actions دارد:
1. در GitHub یک repository جدید بسازید.
2. فایل ZIP پروژه را از حالت فشرده خارج و همه محتویات آن، از جمله پوشه مخفی `.github`، در repository بارگذاری کنید.
3. در بخش Actions، اجرای workflow با نام Build Follower Plus APK را انتخاب کنید.
4. پس از پایان موفق، از بخش Artifacts فایل `follower-plus-debug-apk` را دریافت کنید.
5. فایل `app-debug.apk` را روی گوشی نصب کنید.

این روش به حساب GitHub و اتصال اینترنت نیاز دارد. APK خروجی نسخه آزمایشی است و ورود پیامکی، پرداخت و داده‌های چندکاربره تا زمان اتصال سرویس‌های واقعی فعال نیستند.
